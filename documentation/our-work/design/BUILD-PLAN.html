01 · How we work

Every phase ends at a gate

Agreed 16 Nov 2026 (DECISIONS.md). Changes to the PRD or this plan are logged there too, with the reason.

Buildthe tasks of one phase, on a branch
Test gatepytest Application/V3.1/tests, plus npm run lint && npm run build if the UI changed
Commit & pushonly when the gate passes; PR to main
Teammates pullbefore they start, so everyone builds on working code

Gate fails → fix in the same phase. Nothing broken goes to GitHub.
