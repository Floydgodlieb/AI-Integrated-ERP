# Ethics workshop

## Introduction

For goal for this project is making an AI Integraded ERP system. The reason for it is to make the workflow easyer and faster then using the Odoo webinterface. The worker/ user can have a converstation with the LLM to get the details about the what needs to be done, for register a sale that has been made. By using the Odoo API this can be done and based on the rules that Odoo has.

## Who matters?

In our project are the following stakeholders:
(Find the most important stakeholder and keep the focus on that one)
- The user of the AI Agent 
- The system of Odoo
- The costumer of the company
- The supplier of products to the company

## What matters to them?

The following aspects matter to the stakeholders:

- Have the data secured so it doesn't have the possability to fall in the wrong hands.
- The ease of use should be improved compared to Odoo self, otherwise there would not be a reason to use AI Agent.
- The data must be correct, otherwise the result would have mistakes and that is not good for buisness 
- The costumer should be getting invoiced on time and the right amount and get the right products, (amount and time)

## What is the responsebility of the organisation to take care of that?

- A AI to use for the agent
- Server to host the AI / Agent, Odoo and database on
- Webhooks to use on teams
